# Audio Assets

Place app audio files here:

- `sfx/`: short one-shot sound effects, such as center-dot taps and sent-intent feedback.
- `ambient/`: longer looping ambience, such as white noise for flow mode.

Suggested names:

- `sfx/center_dot_tap.mp3`
- `sfx/intent_sent.mp3`
- `ambient/flow_white_noise.mp3`
